# (앱 이름) 디자인 규칙

이 문서는 디자인 에이전트(소라·코다)가 읽고 지키는 규칙입니다. 판정 스크립트가 읽는 숫자는 `harness/rules.yaml`의 `style`·`frame`에 옮겨 둡니다 (문서에는 숫자를 복사하지 않고 키 이름으로 가리킵니다).

## 정할 것
- 기준 화면 크기 (rules.yaml `frame.attr`)
- 색 팔레트와 쓰임새 (`style.colors`)
- 폰트 (`style.fonts`)
- 모서리 둥글기 (`style.radius_px`)
- 버튼 규칙: 주 버튼 개수, 터치 영역 최소 크기 (`style.max_primary_buttons`, `style.touch_min_px`)
- 외부 리소스·스크립트 허용 여부 (`style.external_allow`, `style.allow_script`)
