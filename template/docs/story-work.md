# (앱 이름) — 작업 흐름 (내 작업 스토리)

내가 이 앱의 화면을 만들 때 거치는 순서를 "나는 ○○한다" 형식으로 씁니다. 멈칫하는 곳에는 ← 멈칫을 붙입니다.

1. 나는 비슷한 앱의 실제 화면을 레퍼런스로 수집한다.
2. 나는 수집한 레퍼런스에서 이번 화면에 반영할 점을 정리한다.
3. 나는 분석 내용과 PRD를 토대로 이번 화면의 설계 문서를 구체화한다.
4. 나는 설계 문서로 컨셉 시안을 만들고 승인하거나 반려한다. ← 멈칫
5. 나는 승인된 시안으로 화면 전체를 디자인한다.
6. 나는 완성된 화면이 디자인 규칙과 "어기면 안 되는 것"을 지켰는지 검토한다.
