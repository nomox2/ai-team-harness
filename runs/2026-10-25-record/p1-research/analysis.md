# P1 리서치 분석 (기록하기)

기준: docs/prd.md 4. 만들 화면의 "기록하기 — 금액 입력, 카테고리 탭, 즐겨찾기, 수입/지출 전환"과 시나리오 1(빠르게 기록).
수집 현황: manual 0개, auto 6개 (uibowl.max_items_per_run 이하). 재사용 2개(이전 explore 실행의 모으미 내역·미니스탁 내역), 새로 수집 4개.

## 한계 (먼저 알려요)
- 금액 입력 화면(숫자 키패드), 카테고리를 한 번 탭하면 기록이 끝나는 화면, 즐겨찾기 탭 화면은 유아이볼에서 찾지 못했어요. "입력"은 유아이볼 분류 표현에 없어 0건이고, 텍스트 필드·날짜 피커 검색은 카드 분실신고 폼 1건만 나왔어요. 이 부분은 대표가 `references/manual/`에 가계부 입력 화면 스크린샷을 넣어 주면 가장 좋아요.
- 농협카드·미니스탁·iM뱅크는 가계부가 아니라서 입력 폼과 선택 시트의 구조만 참고했어요. 주제가 다른 내용(분실신고, 주문내역, 카드 승인)은 가져오지 않았어요.
- 모으미 스크린샷에는 "자산로그" 이름이 보여요. 같은 데이터 묶음이라 모으미 항목으로 넣었어요 (확인 필요).

## 레퍼런스 요약
- 모으미 내역 (references/auto/01-모으미.md): 날짜 머리글에 그날 수입 합계와 지출 합계, 그 아래 항목 목록이에요. 항목마다 카테고리 아이콘, 이름, 작은 태그, "카테고리 · 날짜", 오른쪽 금액이 있어요. 오른쪽 아래에 둥근 + 버튼이 떠 있고, 이 버튼이 기록 추가의 진입점으로 보여요 (이동 결과 화면은 못 봄).
- 미니스탁 내역 (references/auto/02-미니스탁.md): 입금은 빨강 +, 출금은 파랑 −로 기호를 금액 앞에 붙여요.
- 농협카드 입력 폼 (references/auto/03-농협카드.md): 필수 항목 라벨에 빨간 별표, 날짜 입력창 오른쪽 끝에 달력 아이콘, 메모 입력창 아래 "0/20자" 글자 수, 화면 맨 아래에 가로로 꽉 찬 버튼이에요.
- 모으미 카테고리 예산 (references/auto/04-모으미.md): 카테고리를 "아이콘 + 이름 + 금액 + >" 한 줄씩 세로 목록으로 보여요. 위에 총예산·예산 내 지출·남은 금액 3칸 요약이 있어요.
- 미니스탁 선택 시트 (references/auto/05-미니스탁.md): 바텀시트 안에 선택지를 2열 네모 버튼으로 나누고, 선택된 칸만 테두리 색으로 강조해요.
- iM뱅크 월 선택 시트 (references/auto/06-iM뱅크.md): 제목과 닫기 X가 있는 시트에 한 줄씩 항목이 있고 선택 항목만 채운 라디오로 표시해요.

## 비슷한 서비스
- 한국 금융 앱의 색 관례: 모으미와 미니스탁 둘 다 항목 금액에서 입금·수입은 빨강 +, 출금·지출은 파랑 −예요. 두 앱 모두 기호를 금액 맨 앞에 붙여서 색만으로 구분하지 않아요. 대표가 색을 정할 때 참고해요. (이 색이 우리 수입·지출 색인지는 docs/design.md로 확인 필요)
- 카테고리를 아이콘과 이름으로 보여주는 방식이 모으미 내역과 카테고리 예산 두 화면에서 같아요. 기록할 때 고른 카테고리가 내역에서도 같은 아이콘으로 이어지면 알아보기 쉬울 거예요.
- 선택지가 적을 때(수입/지출, 카테고리)는 시트 안에 네모 버튼으로 나열하고, 선택 항목이 많을 때(월)는 한 줄 목록 + 라디오로 보여주는 두 방식이 있어요.

## 반영할 점
- 기록하기 맨 위에서 수입/지출을 먼저 전환할 수 있게 하고, 선택된 쪽만 테두리나 채움으로 강조한다. 전환 방식은 2열 네모 버튼을 쓴다 (근거: references/auto/05-미니스탁.md)
- 카테고리는 "아이콘 + 이름"으로 보여 주고 한 번 탭으로 고른다. 내역과 같은 아이콘을 써서 기록한 항목이 내역에서 같은 모양으로 보이게 한다 (근거: references/auto/04-모으미.md, references/auto/01-모으미.md)
- 날짜는 오늘로 미리 채워 두고, 바꾸고 싶을 때만 오른쪽 끝 달력 아이콘이 있는 입력창을 눌러 고른다. 메모도 선택 항목으로 두어 필수 항목(금액·카테고리)과 구분한다 (근거: references/auto/03-농협카드.md)
- 필수 항목(금액·카테고리)에만 빨간 별표 같은 표시를 하고, 메모 입력칸에는 글자 수 안내를 붙인다 (근거: references/auto/03-농협카드.md)
- 저장 버튼은 화면 맨 아래에 가로로 꽉 채워 항상 보이게 고정한다 (근거: references/auto/03-농협카드.md)
- 금액 미리보기에는 수입은 +, 지출은 −를 맨 앞에 붙이고 색을 다르게 한다. 한국 앱 관례는 수입 빨강, 지출 파랑이다 (근거: references/auto/01-모으미.md, references/auto/02-미니스탁.md)
- 기록하기로 가는 진입점은 내역 화면 오른쪽 아래에 떠 있는 둥근 + 버튼 방식을 한 예로 참고한다 (근거: references/auto/01-모으미.md)
- 날짜를 바꿀 때는 아래에서 올라오는 시트에 한 줄 목록과 선택 표시를 쓰는 방식을 참고한다 (근거: references/auto/06-iM뱅크.md)

## 이번 화면에 주는 제안
- 구성 순서(제안): 수입/지출 전환 → 금액 → 카테고리 → (선택) 날짜·메모 → 저장 버튼. 금액을 입력한 뒤 카테고리를 한 번 탭하면 끝나는 PRD 핵심 흐름과 맞다.
- 즐겨찾기는 자주 쓰는 항목을 칩이나 작은 카드로 카테고리 위에 두는 방식을 제안한다. 레퍼런스에서 직접 확인하지 못했다 (확인 필요).
- 금액 입력은 숫자 키패드를 바로 띄우는 방식이 많다 (일반 지식, 확인 필요).
- 필수 항목(금액·카테고리·날짜)이 기록 항목에서 모두 보여야 한다는 서비스 조건에 따라, 저장 전에 입력 내용이 내역 항목 한 줄(카테고리·날짜·금액) 모양으로 미리 보이면 좋다 (제안).
- PRD 안 할 것(자동 연동, 투자·자산 관리, 공유, 결제·송금, 광고)에 해당하는 요소는 레퍼런스에 있어도 가져오지 않았다.
