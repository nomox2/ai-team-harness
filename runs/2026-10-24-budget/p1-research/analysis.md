# P1 리서치 분석 (예산·설정 화면)

기준: docs/prd.md의 예산·설정 — 이번 달 예산, 카테고리·즐겨찾기 관리. 대표 메모는 예산 페이지 1장과 설정 페이지 1장, 총 2장이다.
수집 현황: manual 0개, auto 5개 (01~05). 모두 홈 실행에서 재사용한 것이고, 이번 실행에서는 유아이볼 검색, WebSearch, WebFetch를 하지 않았다.

## 한계 (먼저 알려요)
- 설정 화면을 직접 보여주는 레퍼런스는 없다. 카테고리 관리나 즐겨찾기 관리 화면은 5개 중 어디에도 없다. 아래 설정 화면 항목은 목록·칩 같은 일반 구조를 빌려 온 것이라 근거가 약하다.
- 예산 화면에 가까운 것은 트레블월렛(05) 하나뿐이다. 이 파일은 `screen: 예산·설정`으로 표시돼 있지만, 내용은 카드 한도의 사용액·잔액 표시다. 이번 달 예산을 입력하거나 수정하는 화면, 카테고리별 예산 화면은 없다.
- 모으미 홈(01)은 가계부 카드와 사람별 남은 용돈을 보여 준다. 예산 설정 화면은 아니고, 남은 금액 표시의 참고일 뿐이다.
- 스크린샷은 이번에 다시 보지 않았다. 아래 내용은 auto 파일의 note와 홈 실행 분석에 적힌 관찰에 기대고 있다.
- 금액 입력 방식(숫자 키패드, 직접 입력 등)과 카테고리 추가·삭제·순서 변경 방식은 레퍼런스로 확인되지 않았다. 필요하면 대표가 `references/manual/`에 예산 설정·설정 화면 스크린샷을 넣거나, 유아이볼 한도가 풀린 뒤 `설정`·`프로그레스 인디케이터` 조합으로 다시 수집하는 편이 안전하다.

## 레퍼런스 요약
- 트레블월렛 (references/auto/05-트레블월렛.md): 한도마다 카드 하나에 큰 금액을 두고, 아래에 진행 막대를 그린다. 막대 양 끝에 "이용금액"과 "이용가능금액"을 적는다.
- 모으미 홈 (references/auto/01-모으미.md): "이번 달 가계부" 카드에 합산 지출을 큰 숫자로 보여주고, 그 아래에 사람별 남은 용돈을 나눠 적는다.
- 토스 홈 (references/auto/04-토스.md): 큰 금액 한 줄과 작은 설명 라벨을 반복하는 카드 구성이고, 하단 탭이 5개다.
- 모으미 내역 (references/auto/02-모으미.md): 항목 한 줄에 카테고리 아이콘·이름·카테고리·날짜·금액이 있다. 전체/수입/지출 칩이 있고, 금액은 수입 빨강 +, 지출 파랑 −다.
- 미니스탁 내역 (references/auto/03-미니스탁.md): 월 머리글 아래에 항목 목록이 있다. 입금은 빨강 +, 출금은 파랑 −로 기호와 색을 함께 쓴다.

## 비슷한 서비스
- 한도·잔액을 보여주는 방식은 "큰 금액 + 진행 막대 + 양 끝 라벨"이다 (05). 홈의 남은 예산 표시와 같은 구조를 예산 화면에서 한 번 더 쓸 수 있다.
- 금액 중심 화면은 큰 숫자 하나에 작은 라벨을 붙이는 구성을 반복한다 (01, 04).
- 카테고리 아이콘과 이름을 한 줄에 묶는 목록 행이 내역에 이미 있다 (02). 카테고리 목록 행의 모양을 맞출 때 참고할 수 있다.
- 색 관례: 모으미(02)와 미니스탁(03) 모두 입금·수입은 빨강 +, 출금·지출은 파랑 −다. 예산 화면에서 "쓴 금액"과 "남은 금액"을 색으로 나눌 때 이 관례와 겹치지 않게 대표가 정할 때 참고한다. 실제 색은 docs/design.md로 확인한다 (확인 필요).

## 반영할 점

### 예산 화면용
- 이번 달 예산 금액을 화면 맨 위 카드에 큰 숫자 하나로 두고, 작은 라벨("이번 달 예산")을 붙인다 (근거: references/auto/05-트레블월렛.md, references/auto/04-토스.md)
- 큰 예산 금액 아래에 진행 막대를 두고, 막대 양 끝에 "쓴 금액"과 "남은 금액"을 적는다. 홈의 `budget-left`와 같은 표시 방식이라 두 화면이 어긋나지 않는다 (근거: references/auto/05-트레블월렛.md)
- 남은 금액은 이번 달 예산에서 쓴 금액을 뺀 값으로 보여 주고, 홈과 같은 숫자를 쓴다 (제안) (근거: references/auto/01-모으미.md, references/auto/05-트레블월렛.md)
- 카테고리별 예산은 카테고리마다 한 줄 또는 작은 카드로 두고, 카테고리 이름 옆에 쓴 금액과 작은 진행 막대를 붙인다 (제안). 카드 하나에 막대 하나를 쓰는 구조를 카테고리별로 반복하는 해석이다 (근거: references/auto/05-트레블월렛.md, references/auto/02-모으미.md)
- 카테고리 행은 내역의 "아이콘 + 이름" 한 줄 형태를 따른다 (근거: references/auto/02-모으미.md)
- 예산 금액을 바꾸는 입력은 큰 숫자를 탭하면 수정하는 방식으로 둔다 (제안, 레퍼런스에 입력 방식은 없음) (근거: references/auto/05-트레블월렛.md)
- 하단 탭을 쓰면 5개 안쪽으로 둔다 (제안) (근거: references/auto/04-토스.md)

### 설정 화면용
- 카테고리 관리는 카테고리 이름 목록으로 보여주고, 한 줄에 아이콘과 이름을 둔다 (제안). 관리 화면 자체는 레퍼런스에 없고 내역의 행 모양만 빌린다 (근거: references/auto/02-모으미.md)
- 즐겨찾기 관리도 같은 목록 행으로 맞춘다. 한 줄에 이름·카테고리·금액을 넣어 기록 항목 규칙(금액·카테고리)과 같은 정보를 보이게 한다 (제안) (근거: references/auto/02-모으미.md)
- 지출/수입 구분이 필요한 곳은 전체/수입/지출 칩을 재사용한다. 카테고리와 즐겨찾기 목록을 지출·수입별로 나눠 볼 때 쓴다 (제안) (근거: references/auto/02-모으미.md)
- 수입은 금액 앞에 +, 지출은 −를 붙이고 색도 다르게 한다. 즐겨찾기 금액에도 같은 규칙을 적용한다 (근거: references/auto/02-모으미.md, references/auto/03-미니스탁.md)

## 이번 화면에 주는 제안
- 예산 페이지는 위에서 아래로 이번 달 예산 큰 숫자와 진행 막대(쓴 금액·남은 금액), 카테고리별 예산 목록 순서를 제안한다 (제안). 이 중 레퍼런스가 직접 받쳐 주는 것은 위쪽 카드뿐이다 (05).
- 설정 페이지는 카테고리 관리와 즐겨찾기 관리 두 묶음 목록을 제안한다 (제안). 레퍼런스 근거가 약하므로 P2에서 구성을 정할 때 대표가 확인하는 편이 좋다.
- 두 페이지 모두 기록하기로 한 번에 가는 진입(`data-nav="record"`)을 유지한다. PRD 일반 규칙이다. 위치는 내역의 오른쪽 아래 + 버튼 사례를 따른다 (제안) (근거: references/auto/02-모으미.md)
- 가져오지 않는 것: 카드 한도 변경·충전·결제(05), 사람별 용돈 나누기와 공유(01), 자산·주식·일정·송금·대출(01, 04). PRD "안 할 것"(자동 연동, 투자·자산 관리, 공유, 결제·송금, 광고)에 해당한다.
- 색의 실제 값, 글자 크기, 간격은 레퍼런스에서 정해지지 않았다. docs/design.md를 따른다.
