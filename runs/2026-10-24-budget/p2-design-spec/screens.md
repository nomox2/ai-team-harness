# 화면 설계 (예산·설정)

기준: docs/prd.md, docs/story-service.md. 근거: runs/2026-10-24-budget/p1-research/analysis.md
대표 메모에 따라 PRD 화면 "예산·설정"을 예산 페이지 1장, 설정 페이지 1장으로 나눈다.
숫자·문구 예시는 화면을 설명하기 위한 임시 값이고 (제안)이다. 색·글자 크기·간격은 정하지 않고 docs/design.md를 따른다.
(반영: n번)의 번호는 analysis.md "반영할 점"의 줄을 위에서 아래로 센 번호다. 예산 페이지용은 1~7번, 설정 페이지용은 8~11번이다.
레퍼런스 한계: 설정 화면을 직접 보여주는 레퍼런스는 없다. 설정 페이지는 근거가 약해서 대표 확인이 필요하다.
두 페이지에는 내역의 기록 항목(`record-item`)을 두지 않는다. 카테고리 행과 즐겨찾기 행은 기록이 아니므로 `record-item` 표시를 쓰지 않는다. 기록 항목이 나오는 곳이 생기면 금액 · 카테고리 · 날짜를 모두 넣는다.

## 예산·설정
목적: 이번 달 예산을 보고 고치고, 카테고리별로 얼마를 썼는지 확인하고(예산 페이지), 카테고리와 즐겨찾기를 정리한다(설정 페이지) (story-service 유저스토리 4의 "이번 달 남은 예산 확인", 유저스토리 2의 즐겨찾기, 유저스토리 1의 카테고리 선택. PRD 4. 예산·설정 — 이번 달 예산, 카테고리·즐겨찾기 관리).

### 예산 페이지
- 요소: 이번 달 예산 카드 — 화면 맨 위, 가장 큰 숫자 하나. 작은 라벨 "이번 달 예산", 그 아래 금액 "600,000원" (예시값, 제안) (반영: 1번)
- 요소: 예산 진행 막대 — 예산 금액 아래, 쓴 비율을 보여주는 막대. 막대 왼쪽 "쓴 금액 272,000원", 오른쪽 "남은 금액 328,000원" (반영: 2번)
- 요소: 남은 금액 일치 — 이 페이지의 "남은 금액"은 홈의 "이번 달 남은 예산 328,000원"과 같은 숫자를 쓴다 (제안) (반영: 3번)
- 요소: 예산 수정 — 큰 예산 숫자를 탭하면 금액을 고치는 입력이 열리고, 버튼 "저장"(초록 채움 `btn-primary`)과 "취소"가 있다. 입력 방식은 레퍼런스에 없다 (제안) (반영: 6번)
- 요소: 카테고리별 예산 제목 줄 — 제목 "카테고리별 예산"
- 요소: 카테고리별 예산 행 — 한 줄에 아이콘 · 카테고리 이름 "식비" · 쓴 금액 "−120,000원" · 작은 진행 막대. 같은 모양으로 "교통", "카페" 등을 반복한다. 카테고리별 예산 금액(예: "식비 200,000원")은 PRD에 없는 값이라 넣을지 대표에게 묻는다 (제안) (반영: 4번, 5번)
- 요소: 기록하기 버튼 — 오른쪽 아래에 떠 있는 둥근 "+" 버튼, 글자 "기록하기", `data-nav="record"`, 초록 채움 버튼(`btn-primary`). 위치는 내역의 오른쪽 아래 + 버튼을 따른다 (제안)
- 요소: 하단 탭 바 — 5개 안쪽. "홈" · "내역" · "통계" · "예산·설정"(현재 화면 강조). 탭 이름은 PRD 화면 이름을 따른다 (제안). 기록하기는 위 + 버튼이 맡는다 (반영: 7번)
- 요소: 설정으로 가는 링크 — 오른쪽 위에 "설정" 글자 버튼 (제안)
흐름: "+" 버튼(`data-nav="record"`) → 기록하기. 오른쪽 위 "설정" → 설정 페이지. 하단 탭 → 홈 · 내역 · 통계. 예산 숫자 탭 → 예산 수정 입력(같은 페이지), "저장" 또는 "취소" → 같은 페이지로 돌아옴. 카테고리별 예산 행 탭 → 통계 (제안).

### 설정 페이지
- 요소: 페이지 제목 줄 — 왼쪽 "‹ 예산" 뒤로 가기, 가운데 제목 "설정" (제안)
- 요소: 지출/수입 구분 칩 — 제목 아래 "전체" · "수입" · "지출" 칩. 아래 두 목록을 지출·수입별로 나눠 볼 때 쓴다. 칩 이름은 내역의 칩을 재사용한다 (제안) (반영: 10번)
- 요소: 카테고리 관리 제목 줄 — 제목 "카테고리 관리", 오른쪽에 "추가" 글자 버튼 (제안)
- 요소: 카테고리 관리 목록 — 한 줄에 아이콘 · 이름. 지출 예시 "식비", "교통", "카페", 수입 예시 "급여". 행 오른쪽에 "편집" 글자 버튼. 삭제 방식은 레퍼런스에 없다 (제안) (반영: 8번)
- 요소: 즐겨찾기 관리 제목 줄 — 제목 "즐겨찾기 관리", 오른쪽에 "추가" 글자 버튼 (제안)
- 요소: 즐겨찾기 지출 행 예시 — 한 줄에 이름 "커피" · 카테고리 "카페" · 금액 "−4,500원". 금액 맨 앞에 −, 수입과 다른 색. 즐겨찾기는 기록이 아니라 날짜는 두지 않는다 (제안) (반영: 9번, 11번)
- 요소: 즐겨찾기 수입 행 예시 — 이름 "월급", 카테고리 "급여", 금액 "+2,800,000원". 금액 맨 앞에 +, 지출과 다른 색. 색은 한국 금융 앱 관례(수입 빨강, 지출 파랑)를 참고하되 최종은 design.md로 정한다 (제안) (반영: 9번, 11번)
- 요소: 기록하기 버튼 — 오른쪽 아래에 떠 있는 둥근 "+" 버튼, 글자 "기록하기", `data-nav="record"`, 초록 채움 버튼(`btn-primary`)
- 요소: 하단 탭 바 — 5개 안쪽. "홈" · "내역" · "통계" · "예산·설정"(현재 화면 강조) (제안) (반영: 7번)
흐름: "+" 버튼(`data-nav="record"`) → 기록하기. "‹ 예산" → 예산 페이지. 하단 탭 → 홈 · 내역 · 통계 · 예산·설정. 칩 탭 → 같은 페이지의 목록만 바뀜. "추가" · "편집" → 입력창이 열림 (이번 설계에서 입력창 모양은 정하지 않음).
