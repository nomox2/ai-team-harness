# (가칭) 가계부 PRD — 최소 5블록

## 1. 한 줄 정의
(가칭)는 혼자 사는 직장인이 돈을 쓰자마자 3초 안에 기록하고, 오늘·이번 달 얼마 썼는지와 남은 예산을 바로 확인하는 가계부 앱이다.

- 핵심: 빠른 기록 — 금액 입력 → 카테고리 한 번 탭으로 끝난다

## 2. 주요 사용자 1명
- 누구: 혼자 사는 20~30대 직장인
- 함께 쓰는 사용자: 사회 초년생, 대학생
- 지금 무엇에 지쳐 있나:
  - 기록이 귀찮아서 가계부를 사흘도 못 간다
  - 월말에야 돈이 어디로 갔는지 안다
  - 카드값이 생각보다 많이 나와서 놀란다
  - 기존 가계부 앱이 너무 복잡하다

## 3. 사용자 시나리오
### 시나리오 1 · 빠르게 기록
1. 사용자가 돈을 쓰자마자 금액을 입력한다
2. 사용자가 카테고리를 한 번 탭해 기록을 끝낸다 (메모·날짜는 선택)
3. 자주 쓰는 항목(예: 커피)은 즐겨찾기를 한 번 탭해 기록한다
4. 수입도 같은 방법으로 기록한다

### 시나리오 2 · 오늘·이번 달 확인
1. 사용자가 오늘과 이번 주에 쓴 돈을 확인한다
2. 사용자가 이번 달 남은 예산을 확인한다

### 시나리오 3 · 어디에 썼는지 보기
1. 사용자가 카테고리별 지출을 본다
2. 사용자가 가장 많이 쓴 곳을 확인한다

## 4. 만들 화면 (5개)
- 홈 — 오늘·이번 주 지출, 이번 달 남은 예산, 최근 내역
- 기록하기 — 금액 입력, 카테고리 탭, 즐겨찾기, 수입/지출 전환
- 내역 — 날짜별 기록 목록, 수정·삭제
- 통계 — 카테고리별 지출 비율, 많이 쓴 곳
- 예산·설정 — 이번 달 예산, 카테고리·즐겨찾기 관리

## 5. 지켜야 할 것 / 안 할 것
### 어기면 안 되는 것
- 모든 기록 항목에 금액·카테고리·날짜가 보인다
- 홈에는 항상 이번 달 남은 예산이 보인다

### 일반 규칙
- 어느 화면에서든 기록하기로 한 번에 갈 수 있다
- 수입과 지출이 색과 기호(+/−)로 구분된다

### 안 할 것
- 은행·카드 자동 연동
- 투자·자산 관리
- 가족·커플 공유
- 결제·송금 기능
- 광고
